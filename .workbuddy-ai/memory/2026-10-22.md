## 修复 build-dist 失败（TS9011 isolatedDeclarations）

- 现象：`npm run build-dist` 在 `build-prod` 的 dts 阶段报 `TS9011: Parameter must have an explicit type annotation with --isolatedDeclarations`（src/vtrender/BasicRenderer.ts 的 `migrateProjection`）。
- 根因：`tsconfig.json` 开启 `isolatedDeclarations: true`，生产构建会跑 `rolldown-plugin-dts`（oxc 生成器）；dev 构建不跑 dts，所以只有 build-prod / BUILD=types 会报错。
- 处理：给 `src/vtrender/` 下被导出类的所有方法补齐参数类型与返回类型，新增 `BasicRendererTileSpec` / `BasicRendererDrawSpec` / `BasicRendererConsumer` / `BasicRendererRenderRef` 四个导出类型描述 renderTiles 的入参与句柄；`setPaintProperty` / `setLayoutProperty` 的 `prop` 保持 `string`（外部传动态属性名），内部用 `prop as keyof AllPaintProperties / AllLayoutProperties` 收窄；`BasicPainter.resize` 补 `: void`。
- 验证：`npx cross-env BUILD=types npx rolldown -c rolldown.config.ts` 与 `npm run build-dist` 均通过，`dist/maplibre-gl.d.ts` 正常产出。
- 遗留（改动前就存在，未修）：
  - `npx tsgo --noEmit` 在 vtrender 仍有 5 个错误：`getContext` 返回类型、`BasicPainter.renderText/renderIcons` 未声明、`transform._helper` 私有、`Tile.holdingForFade` 不存在（后者疑似运行时 bug，`releaseSymbolFadeTiles` 会抛错）。
