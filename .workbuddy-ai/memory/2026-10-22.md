## 修复 build-dist 失败（TS9011 isolatedDeclarations）

- 现象：`npm run build-dist` 在 `build-prod` 的 dts 阶段报 `TS9011: Parameter must have an explicit type annotation with --isolatedDeclarations`（src/vtrender/BasicRenderer.ts 的 `migrateProjection`）。
- 根因：`tsconfig.json` 开启 `isolatedDeclarations: true`，生产构建会跑 `rolldown-plugin-dts`（oxc 生成器）；dev 构建不跑 dts，所以只有 build-prod / BUILD=types 会报错。
- 处理：给 `src/vtrender/` 下被导出类的所有方法补齐参数类型与返回类型，新增 `BasicRendererTileSpec` / `BasicRendererDrawSpec` / `BasicRendererConsumer` / `BasicRendererRenderRef` 四个导出类型描述 renderTiles 的入参与句柄；`setPaintProperty` / `setLayoutProperty` 的 `prop` 保持 `string`（外部传动态属性名），内部用 `prop as keyof AllPaintProperties / AllLayoutProperties` 收窄；`BasicPainter.resize` 补 `: void`。
- 验证：`npx cross-env BUILD=types npx rolldown -c rolldown.config.ts` 与 `npm run build-dist` 均通过，`dist/maplibre-gl.d.ts` 正常产出。
- 遗留（改动前就存在，未修）：
  - `npx tsgo --noEmit` 在 vtrender 仍有 5 个错误：`getContext` 返回类型、`BasicPainter.renderText/renderIcons` 未声明、`transform._helper` 私有、`Tile.holdingForFade` 不存在（后者疑似运行时 bug，`releaseSymbolFadeTiles` 会抛错）。
  - `npx eslint src/vtrender` 仍有 19 error / 8 warning（no-restricted-syntax forEach、prefer-optional-chain、logical-assignment-operators 等），属该 fork 既有代码风格问题。
- 备注：仓库工作区里有大量未提交的 WeatherEarth 定制改动，`git diff` 会把它们一起显示出来。

## 新增 hxgis 私有版本发布链路

- 参照 `F:/Dev/2026/electron-cesium-v2/src/renderer/src/cesium-weather-webgpu`（cesium 的私有化做法：版本号 `-hxgis.N` + `publishConfig` 指向 `https://repo.hxgis.com/repository/npm-hosted/`，dist-tag `hxgis`）。
- 新增 `build/publish-hxgis.ts`：读 package.json → 从 registry（`npm view`）与本地版本取最大 `-hxgis.<n>` 再 +1 → 写回 package.json → `npm run build-dist` → `npm publish --tag hxgis --registry <私有源> --ignore-scripts`。
- package.json：新增 `publishConfig`（registry + tag）与脚本 `version:hxgis`（仅改版本）/`publish:hxgis`/`publish:hxgis:dry`。
- eslint.config.js：`allowDefaultProject` 加 `build/publish-hxgis.ts`（该文件不在 tsconfig include 内，不加会因 projectService 报错）。
- 已验证：`--help`、`--bump-only`（6.15.0 → -hxgis.1 → -hxgis.2）、`--dry-run --skip-build`（打包 765 文件、6.3MB、含 12 个 dist 产物）。本机访问不到 repo.hxgis.com，版本号回退为仅按本地递增并告警。
- 注意：`npm publish` 会触发 `prepare`（跑 codegen），脚本用 `--ignore-scripts` 保证发布物就是刚构建的 dist。
